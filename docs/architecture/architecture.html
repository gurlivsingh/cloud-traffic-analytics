Infrastructure as codeAWS CloudFormation · stack "traffic-analytics" One command (python deploy/aws.py up) creates every resource in this diagram: S3, security groups, RDS, EC2 + Elastic IP, CloudFront, log groups, alarms, dashboard and SNS. On first boot the server installs itself from GitHub, loads the dataset into S3 and RDS, trains the models and signals success. python deploy/aws.py down deletes everything.
